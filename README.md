# GharKhoj PWA

A browser-based, iPad-friendly version of GharKhoj. No Node.js installation is required on the iPad.

## Use on iPad
This folder needs to be hosted on a web host. Once hosted, open it in Safari and use:
Share → Add to Home Screen

It will behave like an app.

## Current features
- GharKhoj branding
- Kathmandu location
- Buy/Rent toggle
- Search
- Categories
- Property cards
- Nepal sample property data
- iPad/mobile responsive design
- Add to Home Screen PWA support
